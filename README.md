# portscan

Небольшой Go-пакет для проверки доступности TCP-портов. Подходит, когда нужно
быстро узнать, какие порты открыты на одном или нескольких хостах, не привязывая
логику к CLI, HTTP-серверу или базе данных.

Используется обычное TCP Connect-сканирование из стандартной библиотеки Go:
пакет пытается установить соединение и возвращает результат для каждого порта.
Это не аналог Nmap: здесь нет SYN- и UDP-сканирования, raw sockets, определения
ОС и обхода сетевых ограничений.

Внешние зависимости не используются.

## Быстрый старт

```go
package main

import (
	"context"
	"fmt"
	"time"

	"portscan"
)

func main() {
	scanner, err := portscan.New(
		portscan.WithConcurrency(100),
		portscan.WithConnectTimeout(500*time.Millisecond),
	)
	if err != nil {
		panic(err)
	}

	results, err := scanner.Scan(
		context.Background(),
		[]string{"192.168.1.10", "example.org"},
		portscan.Combine(
			portscan.Ports(22, 80, 443),
			portscan.Range(8000, 8010),
		),
	)
	if err != nil {
		panic(err)
	}

	for result := range results {
		fmt.Printf("%s (%s):%d — %s\n", result.Host, result.IP, result.Port, result.State)
	}
}
```

## Как пользоваться

Создайте `Scanner` один раз через `New`, а затем вызывайте `Scan`. Экземпляр
сканера можно переиспользовать и безопасно вызывать из нескольких горутин.

- `WithConcurrency(n)` — максимум одновременных попыток подключения. По
  умолчанию: `64`.
- `WithConnectTimeout(d)` — таймаут одной попытки подключения. По умолчанию:
  `1s`.
- `Ports(22, 80, 443)` — отдельные порты.
- `Range(8000, 8010)` — включительный диапазон портов.
- `Combine(...)` — объединение списков и диапазонов.

`Scan` сразу возвращает канал результатов. Его нужно вычитывать до закрытия:

```go
for result := range results {
	if result.State == portscan.Open {
		fmt.Printf("открыт: %s:%d\n", result.IP, result.Port)
	}
}
```

## Что содержит результат

```go
type Result struct {
	Host     string        // цель в том виде, в котором её передал пользователь
	IP       net.IP        // конкретный адрес, к которому выполнялось подключение
	Port     uint16
	State    State
	Duration time.Duration // длительность попытки
	Err      error         // исходная ошибка, если она была
}
```

Возможные состояния:

- `open` — TCP-соединение установлено;
- `closed` — хост явно отклонил соединение;
- `timeout` — время ожидания подключения истекло;
- `unreachable` — сеть или хост недоступны;
- `canceled` — операция прервана через `context.Context`;
- `error` — другая ошибка, например ошибка DNS-разрешения.

Состояние определяется по типам ошибок и системным кодам, а не по тексту
ошибки.

## Цели и порты

Поддерживаются IPv4, IPv6 и DNS-имена. Повторяющиеся хосты и порты сканируются
один раз. Если DNS-имя возвращает несколько IP-адресов, будет выполнена проверка
каждого адреса. Если имя не разрешается, для каждого запрошенного порта придёт
результат со статусом `error`.

До начала сканирования пакет проверяет входные данные. `Scan` вернёт ошибку для:

- пустого или некорректного хоста;
- пустого набора портов;
- порта `0` или порта больше `65535`;
- обратного диапазона, например `Range(1000, 1)`;
- `nil`-контекста.

Ошибки можно проверять через `errors.Is`, например
`errors.Is(err, portscan.ErrInvalidPort)`.

## Отмена и нагрузка

Передавайте свой `context.Context` в `Scan`. При отмене контекста пакет перестаёт
ставить новые задачи в очередь и завершает уже начатые подключения. Медленное
чтение результатов создаёт обратное давление, но число одновременных TCP-диалов
всё равно не превысит значение `WithConcurrency`.
